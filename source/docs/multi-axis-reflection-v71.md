The current adapter supports reviewed hostile plain vanilla Arrow only. Melee, critical/burning/piercing/potion arrows, friendly/player-owned arrows and unknown projectile classes remain ordinary native behavior. This is not universal damage reflection or a 5m interception sphere.

A facet crossing must belong to either a completed native flight segment or the exact current native sweep that selected this defender. The original findHitEntity return is unchanged. The same original ProjectileImpact callback must complete uncanceled, with identities, geometry, permissions, arrow metadata and resources still valid.

Native Arrow.tick invokes hitTargetOrDeflectSelf before its actual movement and then rereads velocity. Successful NEW442 therefore reverses the same entity at its actual current position, not at a fabricated distant facet point. The reverse next-step segment must be loaded and free of solid/fluid/other-body obstruction; ambiguous overlap or obstruction refuses free. No setPos, owner replacement, entity cloning, arbitrary second hurt call, damage multiplier, fall immunity or velocity freeze is introduced. Subsequent native movement, drag, gravity, armor, handheld shields and iframes remain authoritative. Actual arrow ownership and pickup/lifetime metadata remain unchanged.

## Payment and lifecycle

The fee is the pinned ordinary noncritical native raw arrow amount: speed cast to float; weapon-present base damage cast to float; product clamped then ceiled as native code does. Allowed speed≤8 and base≤64 bound the amount. It is a provisional raw-kinetic cost, not a claim to predict foreign hurt callbacks or post-armor damage.

The entire fee must be available from base S plus the existing lower half-S reserve. Debit is all-or-nothing, base first then lower, preserving upper. No activation, relearning, category switch or reconnect refills a balance. The sole shared recovery budget remains 1% of base S per genuine eligible tick after the existing quiet period; NEW442 admits lower recovery only and blocks recovery while active. It does not enable EM/MD defenses or generic vector hurt absorption.

An opaque native impact payment validates before resource publication. Quota, persistent once-per-arrow denial mark and physical reversal are committed before resource observers or visual receipts. An exception after publication is a paid uncertain terminal result, not normal success, retry or automatic refund. Ordinary cancellation/refusal is free. The marker survives unload and reload and excludes competing old steering paths; it is not a new attack permit.

Provisional quota: at most one reflection per facet per real server tick and four total per rolling20 online player ticks. Native remaining clocks persist through switching/reconnect; no offline credit. Activation/upkeep/CD reuse the continuous NEW412 curves (q1→5): CP2/1/.4/.1/.02, per20ticks .25/.125/.05/.0125/.0025, CD10/5/3/2/1 with physical4tick restart floor. Toggle off is free.
