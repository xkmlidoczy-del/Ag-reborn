# Asset metadata and credits

The public source snapshot removes non-rendering text and EXIF metadata from selected generated PNGs to reduce disclosure of local authoring details. Image pixels, alpha, palettes and color profiles are preserved. Some original upstream PNG metadata remains where existing runtime and test contracts verify the original file hash; those retained metadata were checked for local usernames, paths and contact information.

The original FX4 procedural-art source annotations referred to `scripts/fx4/materials.py`, `scripts/fx4/core.py`, `scripts/fx4/tech.py` and `scripts/fx4/air.py`. Original AcademyCraft/LambdaLib authorship and the licenses of other bundled assets remain in `NOTICE`, `LICENSE` and the associated third-party notices.
