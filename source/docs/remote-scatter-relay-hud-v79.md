# NEW253 readable HUD (.79)

This client-only update separates the current relay state, concise input help, and an authenticated “Last result” note. It uses the native GUI font and wraps within the actual configured CP, key, notification, chat and recovery-panel rectangles, with crosshair/hotbar exclusion. It does not alter resource values. Tight layouts omit optional help before outcome text; if complete status and result cannot fit safely, status takes precedence. Extremely small/crowded layouts may show no relay panel rather than clip text.

The note records only an accepted local FIRE receipt: damage confirmed, damage absorbed, no damage confirmed, or shot blocked. A later ACTIVE preview does not renew or erase it. Text expires after at most 25 effective client ticks (normally 1.25 seconds at 20 TPS); low client tick rates are not a wall-clock guarantee. It is explicitly historical, never a current protection/hit indicator. A fresh accepted local input, EDIT, ENDED, actual lease expiry, pause/menu, hidden GUI/debug view, ineligible state, world/player/connection change, abort or resource reload discards it. Hidden notes are not queued for replay.

World effects retain the original six-client-tick flash, route geometry, material, occlusion, server 400-tick lifetime, payment and native damage contracts. The original shared 4096-vertex scene cap is retained: the GUI uses at most 79 complete source code points with shadow (158 quads) plus two panel fills. Over-budget help is omitted, not shrunk or clipped; source spaces count conservatively. No textures or server protocol changed.
