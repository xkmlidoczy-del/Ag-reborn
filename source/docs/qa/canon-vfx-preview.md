# 八系能力视觉验收清单

这些条目是视觉设计映射，不代表技能已开放或完成，也不代表客户端画面已验收。真实施法与本地预览必须分别检查。

1. 客户端启动时设置 JVM 参数 `-Dacademy.visual.qa=true`，进入可加载的世界。
2. 执行 `/aca_canon_vfx <技能ID> <start|active|hit|end>`。预览在视线前方生成，不施法、不扣资源，也不能证明网络传输。
3. 对每个技能在第一人称、第三人称和远距离旁观位置检查各阶段，记录遮挡、粒子密度、声音和结束后的清理。
4. 对已实现技能再通过真实施法检查服务端发包、施法者与旁观者的画面、取消或换维后的清理，以及失败施法不产生成功特效。

每客户端最多同时保留 24 个视觉事件，每两 tick 最多生成 144 个粒子；服务器每玩家每 tick 最多 8 条、每服务器每 tick 最多 128 条，广播半径 64 格。几何使用原版粒子材质，当前没有独立 GPU 材质验收。

已编译 QA 客户端后，可用 `qa/canon-vfx-preview.script` 依次截取十种代表动作的四个阶段：

```sh
python3 qa/run-prepared-client.py canon-vfx --props academy.visual.qa=true --script "$(cat qa/canon-vfx-preview.script)"
```

此脚本只驱动本地预览。实际拍摄时还需检查截图是否有可见主体、预期轮廓及声音；进程成功退出不等于视觉合格。

## 双客户端真实施法矩阵

使用同一测试服、不同账号和相同构建。A 为实际施法者，B 为旁观者；在独立测试世界准备技能、资源、有效目标及合法介质。每行分别保存 A 第一人称、A 第三人称、B 近距和 B 约 40 格四组画面，记录服务端日志、客户端日志、技能 ID、阶段、坐标与实际时间。

| 系 | 代表情境 | 需要观察 |
|---|---|---|
| 心理掌控 | 实际探测和干扰有效敌人 | 遥控/认知形态、成功与拒绝的差别 |
| 未元物质 | 施展翼与构体后移动、终止 | 翼与构体跟随角色；旁观者可见；结束后消失 |
| 氮气装甲 | 激活压缩壳并触发真实近拳 | 壳跟随角色；近拳是近身压缩，不显示远程激光 |
| 空力使 | 支撑面喷射与可作用目标方向 | 表面喷出点、方向性压力锥，不能误画普通激光 |
| 水流操作 | 合法水源射击与成功水源搬运 | 源与目标位置、连续水流；拒绝搬运时不出现成功轨迹 |
| 浮空回线 | 浮升与缓降合法目标 | 上升和下降标记区分；表现为浮力而非泛重力 |
| 液影 | 实体液影移动及其真实触觉/听觉感知 | 液体轮廓、接触落点；不暗示无设备的天生视觉 |
| 纸系 | 滑翔、纸刃和成功放置纸构造 | 纸翼、刃与构造轮廓分辨；到期后视觉与实体均结束 |

补充负例：无资源、未学习、无有效介质、受保护位置和超出服务器广播半径；在延迟、切维、玩家断线、旁观者换世界、资源包重载时检查状态清理和音画一致。未通过或未执行的项目应逐行记录，不以本地预览截图替代。

| 系 | 基础技能 | 视觉形态 |
|---|---|---|
| 心理掌控 | mental_probe / mental_disrupt / mental_out_crowd | 遥控面板与指向 / 认知螺旋 / 多目标框 |
| 未元物质 | dark_blade / dark_wings / dark_construct | 短刃 / 六翼 / 轨道碎片 |
| 氮气装甲 | nitrogen_armor / nitrogen_punch / nitrogen_dome | 折射壳 / 压缩近拳 / 穹面 |
| 空力使 | aero_jet / aero_launch / aero_barrage | 后喷流 / 表面定向流 / 压力锥 |
| 水流操作 | hydro_whip / hydro_shield / hydro_domain | 波动水鞭 / 水幕 / 多层涟漪 |
| 浮空回线 | float_lift / float_rescue / float_field | 垂直升力线 / 浮力轨迹 / 多点升力 |
| 液影 | liquid_scout / liquid_strike / liquid_shadow_field | 地面液影轮廓 / 近击液流 / 连通涟漪；远程视觉需外置镜头 |

其他 A 组技能的逐 ID 意图见 `tmp/canon-formal/a-skills.json`；当前仅有元数据标为已实现、且实际注册的技能可以从真实施法发出视觉事件。预览支持已建立视觉映射的规划 ID，不代表这些技能已经可玩。
