# ACA Mech 内置模块

Ag 重生 a3.63-mech.2 在同一个 JAR 中内置 ACA Mech 0.4.5。机甲仍以 `acamech` 模组和命名空间加载，保留原有实体、物品和配方标识。机甲网络协议从 5 更新至 6；客户端和服务器需使用同一整合版本。升级时应移出旧的独立 ACA Mech 和旧的 Ag 重生 JAR。

机甲源代码及游戏资源在 `../../src/mech/`，测试驱动在 `../../src/mechQa/`。Gradle 用 `mechJar` 构建内置模块，`jar` 将它与现有 GeckoLib 一起打包；测试代码不会放入生产包。Java 21 下使用 `./gradlew jar mechQaJar`。素材版权、上游来源及 MIT/CC0 许可见本目录 `NOTICE.md`、`LICENSE`、`ASSET-LICENSE.md` 与 `CC0-1.0.txt`；可编辑模型和完整设计工程仍在独立的 ACA-mech 项目。

三个部署箱既有普通材料配方，也有基于 ACA 材料的配方；重型电池可给机甲补能。G 是机甲远程，也是旧枪械的默认射击键；坐在机甲内时旧枪械不会因为该键射击。可在按键设置中重新绑定。

0.4.4 的台阶、下坡步态和 0.4.5 的驾驶舱、蓄力及命中特效已同步。三张原始贴图在 `art/imagegen/v0.4.5/`；使用 `requirements-art.txt` 配置 Python 环境后运行 `tools/bake_cockpit_fx.py` 可重新导出机甲资源。可编辑模型和完整原项目仍在独立的 ACA-mech 工程。

内置 0.4.5 的服务端侧没有全局伤害事件处理器，数据包仅添加机甲自身配方；原生测试覆盖其加入严格伤害／采矿契约后的识别。其他机甲版本、额外未审查模组及数据包仍按原契约拒绝。多人外网、高延迟、额外模组组合和所有技能对机甲的交互未在此次逐项验证。
