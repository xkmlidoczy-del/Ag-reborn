# ACA Mech · 学园机库

Original code and documentation: MIT. The converted model files, new pixel
atlases and item icons are released under CC0 1.0 to the extent the
contributors hold rights in those assets. Version 0.2 and 0.3 material sources were
generated with the built-in ImageGen tool. Each project PNG is a Box UV bake
of the corresponding generated sheet. See the ImageGen prompts and material sheets in each model release.
The 0.4.1 machining material sheet was generated with the built-in ImageGen tool (art/v0.4.1/imagegen).
The 0.3.1 cockpit glass and bezel were generated with the built-in ImageGen tool;
`art/hud/` stores the original and prompt, and the instruments are rendered by the client.

Model source: ATLAS / 09, AETHER / 02 and SERAPH / 03 by Ramon Linares,
at commit 1b8fb9d54160215c071c5a29a49b1c36dc01f0df:
https://github.com/RamonLinares/atlas-09/tree/1b8fb9d54160215c071c5a29a49b1c36dc01f0df

Upstream asset dedication: https://github.com/RamonLinares/atlas-09/blob/1b8fb9d54160215c071c5a29a49b1c36dc01f0df/ASSET-LICENSE.md
The upstream GLBs are used as inputs to rigid cuboid fitting. Their baked
animations and mesh data are not bundled in the mod. The visual references
Pacific Rim and ARK are not asset sources. Ag重生 is a separate mod; no code,
classes, models, textures or sounds from its archive are distributed here.
