# ACA Domain 67 · 六七餐厅

a3.87-rc4 的百人外观整合版内嵌六七餐厅 1.2.2，沿用 `aca_domain67` 的物品、实体及存档 ID。客户端和服务端各装一份 Ag 重生整合 JAR，升级时移出此前单独安装的六七餐厅 JAR。

展开与收回领域的角落提示只显示给施法者，两个状态共用一个提示位。广播、滚木和盒饭的成功反馈通过原有动作、声音与场景特效呈现。连续按键时，同一项冷却提示会在对应的冷却窗口内合并。

在创造栏「领域展开 · 六七餐厅」取得鎏金「67」圣徽扩音器，并放入背包。

| 默认键 | 操作 |
| --- | --- |
| `[` | 展开餐厅或收起现有领域 |
| `]` | 广场广播，引导附近生物 |
| `;` | 领域内触发万向金箍滚木 |
| `'` | 领域内施放 78 元盒饭连携 |

可在 Minecraft「控制」里修改四个键位。任一手持 Academy 枪械时，领域快捷键暂停响应。原始版本的三个道具仍可在创造栏取得。

餐厅收起时按波次恢复临时改造的地表。暂未加载的区块在重新加载后继续恢复。地表变化遵循 Academy 的地形规则，剧情都市只显示领域演出。滚木与盒饭通过本体的原生伤害结算。霸体盾可以抵抗拉拽、上抛和击退，护盾耗尽的当击仍抵抗本次位移。

## 构建和来源

`./gradlew jar` 生成整合 JAR，`./gradlew domain67QaJar` 单独生成用于 `aca_domain67_qa` 命名空间的测试模组。验收时在测试专服的 `mods` 中放置整合包与测试模组。
