# ACA Omnitrix 0.7.0 整合

Ag 重生从 a3.71 起内置三只变身腕表和阿斯卡隆，适用于 Minecraft 1.21.1、NeoForge 21.1.252 和 Java 21。升级前备份存档，移出旧 Ag 重生及独立的 Omnitrix、ACA Mech、ACA Fauna 和 ACA bio HUM JAR。客户端和服务端都安装同一份整合 JAR。

创造模式可在「ACA 变身腕表」栏领取。生存模式可用指南针右击学园都市公告板领取主世界坠落舱地图；也可以在新生成的主世界区块探索坠落舱，再通过封存台装配其他两只表。

- 手持右键佩戴，按 `Y` 抬腕，滚轮或方向键选择形态，回车确认。长按 `Y` 可解除基础表及 X 表的变身。
- 主模组能力开关使用 `V`。在整合版中，按 `M` 切换阿斯卡隆覆甲，双击空格起飞。独立版的覆甲设置不会覆盖整合版的默认键，自定义覆甲键可以在控制选项中重新设置。
- 持表或持剑时，左右键优先执行装备操作。放下装备后，左右键恢复当前 ACA 技能槽行为。
- 腕表与圣剑保留 `aca_omnitrix` 的物品及玩家数据 ID，使用原有协议 8。旧腕位与装备会随存档读取。

Gradle 从 `source/src/omnitrix/` 编译 0.7.0 运行源码和资产，并将 Omnitrix 作为 NeoForge 内嵌模块写入主 JAR。来源、署名及许可证见 [NOTICE](NOTICE.md) 和 [licenses](licenses/)。

## 2026-11-18 实机验收

本机 Minecraft 1.21.1、NeoForge 21.1.252、JDK 21。通过独立专服与两个图形客户端，验证了公告板换图、定格与终焉的中途同步、腕表接管与重连，以及保留物品开启和关闭时的腕位状态。单人生存及专服生存均达到 9×，松键首刻到 20 刻位移为 0。客户端复核了 32 种外观、21 组主动技能、11 种畸变攻击与 0.3.0 腕位数据。主模组通过 71 项巨兽 GameTest、`coreTest`、`dataTest` 及 `macroRulesTest`。
