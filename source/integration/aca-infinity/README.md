# ACA Infinity 0.5.2 整合

Ag 重生 a3.79 内置 **ACA Infinity 0.5.2**（乌鲁无限手套、六颗无限原石与可驾驶圣殿二号旗舰），与主模组、Omnitrix、机甲、动物及人物 NPC 共用同一份整合 JAR，无需额外安装独立手套模组。

## 获取与生存探索

- 创造模式可在「ACA 无限宝石」物品栏直接领取无限手套、六颗原石与圣殿二号信标。
- 生存模式可在主世界探索生成的宇宙宝库（Cosmic Vault）获取原石，并按原版配方锻造无限手套与旗舰信标。

## 键位与交互（整合版零冲突）

- **装备与镶嵌**：手持无限手套右键穿戴；副手持有原石并潜行右键或打开选石轮盘可镶嵌原石。
- **全息扇面选石（U1）**：默认按 `[`（左方括号）在手套上方展开无黑框 3D 椭圆轨道选石星盘，滚轮切换原石，松开或点击确认；主界面采用准星发丝微弧与极简星点，零视野遮挡。
- **原石主动技与响指**：佩戴手套或手持原石时按 `H` 释放当前原石能力（潜行 + `H` 触发次级形态，如空间抓怪换位、时间加速/时停弹幕反拍、现实化蝶回血、灵魂逃跑与禁碰撞、心灵四层模组 AI 强制支配）；集齐六颗原石后按 `J` 触发响指，接入本体 `NativeCombatDamage` 统一破限管线。
- **复施间隔**：生存模式下六颗原石主技 4 刻、副技 6 刻，六石响指默认 10 刻。服务器可在 `cosmic_skills.snapRepeatTicks` 配置响指间隔。
- **圣殿二号旗舰驾驶**：仅在乘坐旗舰时激活 `G`（主炮齐射）、`B`（轨道轰炸）、`V`（视角切换），下船后原按键完全归还主模组能力与机甲系统。
