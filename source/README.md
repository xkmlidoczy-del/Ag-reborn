# Ag:reborn source

The project overview, build instructions, privacy-sanitized snapshot scope and status are in the [repository README](../README.md). This is the `0.81.5-city-a3.63` gameplay source for Minecraft 1.21.1, NeoForge 21.1.252 and Java 21.

Use `./gradlew jar` to build. `src/main` contains the mod, `src/test` contains regression tests and fixtures, `qa` contains optional verification helpers, and `docs` contains technical notes and additional license notices. Some historical tests require external game runtimes or reference evidence and are not covered by a build alone.

Original work: [AcademyCraft by Lambda Innovation](https://github.com/LambdaInnovation/AcademyCraft). This is an unofficial port and expansion. Preserve `LICENSE`, `NOTICE` and component-specific notices; see the repository README for the upstream additional terms.
