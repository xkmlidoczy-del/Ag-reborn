# Ag:reborn source

The [repository README](../README.md) covers build instructions and snapshot scope. This is the `0.81.5-city-a3.77` source for Minecraft 1.21.1, NeoForge 21.1.252 and Java 21. Gradle builds the embedded ACA bio HUM 0.9.1, Fauna 0.1.18, Mech 0.4.5, Omnitrix 0.8.0, and Infinity 0.5.1 modules from `src/hum`, `src/fauna`, `src/mech`, `src/omnitrix`, and `src/infinity`.
